# 🔍 سیستم لاگ‌گیری و تجزیه ترافیک کاربران Mikrotik

برنامه‌ای **پیشرفته** و **تفصیلی** برای نظارت کامل بر کاربران Mikrotik:

✅ **گزارش ترافیک کامل** - حجم + سرعت + IP منشاء/مقصد + URL  
✅ **فعالیت کاربر** - بر اساس زمان (روز، ماه، سال)  
✅ **نمایش تمام اتصالات** - IP و پروتکل  
✅ **جستجوی پیشرفته** - بر اساس گروه و نام  
✅ **صادرات گزارش** - برای ارائه و تجزیه

---

## 🚀 نصب و راه‌اندازی **آسان**

### **الف) نصب وابستگی‌ها**

#### 🖥️ **Windows:**
```bash
# فایل install.bat رو دابل کلیک کن
```

#### 🐧 **Linux/Mac:**
```bash
bash install.sh
```

#### 🔧 **یا دستی:**
```bash
pip install -r requirements.txt
```

---

### **ب) تنظیمات Mikrotik**

1. **فایل `.env` رو باز کن** (با Notepad)
2. **اطلاعات خود رو وارد کن:**

```env
MIKROTIK_HOST=192.168.1.1        # 👈 IP Mikrotik
MIKROTIK_USER=admin               # 👈 نام کاربری SSH
MIKROTIK_PASSWORD=رمز_عبور        # 👈 رمز عبور
MIKROTIK_PORT=22                  # 👈 پورت (معمولاً 22)
```

**مثال واقعی:**
```env
MIKROTIK_HOST=192.168.88.1
MIKROTIK_USER=admin
MIKROTIK_PASSWORD=123456
MIKROTIK_PORT=22
```

---

### **ج) اجرای برنامه**

```bash
python main.py
```

## 📊 منو و قابلیت‌ها

```
1️⃣  📊 گزارش کامل ترافیک کاربر
    ↳ حجم دانلود/آپلود
    ↳ سرعت دریافت/ارسال
    ↳ IP‌های منشاء و مقصد
    ↳ تعداد اتصالات

2️⃣  🕐 فعالیت کاربر در بازه زمانی
    ↳ جستجو بر اساس تاریخ
    ↳ IP‌های فعالیت در بازه
    ↳ تعداد اتصالات روزانه

3️⃣  🌐 IP‌های دسترسی
    ↳ لیست IP منشاء
    ↳ لیست IP مقصد
    ↳ تعداد دفعات رفتن به هر IP

4️⃣  🔗 اتصالات فعال
    ↳ پروتکل مورد استفاده
    ↳ وضعیت اتصال
    ↳ مدت اتصال

5️⃣  👥 لیست تمام کاربران
    ↳ گروه هر کاربر
    ↳ وضعیت فعال/غیرفعال
    ↳ محدودیت‌های سرعت

6️⃣  🔎 جستجو بر اساس گروه
    ↳ لیست گروه‌ها
    ↳ کاربران هر گروه

7️⃣  📈 مقایسه ترافیک
    ↳ (بزودی)

8️⃣  💾 صادرات گزارش
    ↳ گزارش کامل تمام کاربران
    ↳ ذخیره در فایل
```

## 🔧 حل مشکلات

### ❌ **خطای "Connection refused"**
```
✅ حل:
   1. IP Mikrotik رو بررسی کن
   2. SSH رو فعال کن:
      /ip service set ssh disabled=no
   3. Firewall رو چک کن
```

### ❌ **خطای "Authentication failed"**
```
✅ حل:
   1. نام کاربری و رمز رو تأیید کن
   2. کاربر دسترسی SSH داشته باشد:
      /user print
      /user set admin group=full
```

### ❌ **برنامه کند است**
```
✅ حل:
   1. Mikrotik رو ری‌استارت کن
   2. تعداد اتصالات کم کن
   3. بیشتر رم برای Mikrotik تخصیص بده
```
